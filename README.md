# diffd

A live code review for your agent's changes. An agent shares a diff through
MCP, you read it in a GitHub-quality, difftastic-powered, vim-driven viewer,
comment on code, and the agent answers inline while it keeps editing.

**Status: design.** Nothing is implemented yet.

- [`docs/DESIGN.md`](docs/DESIGN.md) is the design under discussion.
- [`docs/mockup.html`](docs/mockup.html) is a clickable mockup of the review
  page. Open it in a browser and press `?` for keys.
